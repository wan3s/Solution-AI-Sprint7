# Распознавать и оцифровывать сканы документов, приложенных к кредитной заявке

## Готовность данных

| Поле | Значение |
| --- | --- | 
| Источник правильного ответа | Сам пользователь - он проверяет, что данные распознались корректно | 
| Качество | Качество должно быть высокое - у нас есть накопленная база документов, которые распознавались вручную |
| Объём по важному классу | Нет какого-то важного класса |
| Разметка | Есть набор распознанных вручную документов |
| Cмещение отбора | - | 
| Репрезентативность | не известно |
| Право использовать | Нужно уточнить у юристов - могут быть чувствительные данные |
| Владелец | Отдел кредитования |
| Вердикт | Пока использовать нельзя - нужно уточнить у юристов |
